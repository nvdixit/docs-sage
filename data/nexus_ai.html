NexusAI: Internal Knowledge Assistant

Summary: NexusAI is our secure, enterprise-grade internal search and summarization tool. It runs completely air-gapped on our local workstations/servers utilizing Gemma 4 12B via a custom Retrieval-Augmented Generation (RAG) configuration.

1. System Architecture

NexusAI avoids public cloud API vulnerabilities by maintaining zero data retention policies. The application leverages a locally orchestrated stack:

  • Base LLM: Google's open-weights Gemma 4 12B-it running locally through Ollama/vLLM.
  • Vector Database: ChromaDB instance indexing company PDFs, internal Confluence markdown exports, and tech specs.
  • Embedding Model: HuggingFace all-MiniLM-L6-v2 running locally on CPU/GPU clusters.

2. Core Features

3. Quick Start for Developers

If you want to spin up your local development environment for NexusAI, clone the repository and run the setup script:

# 1. Pull the required model locally via Ollama
ollama run gemma4:12b

# 2. Install repository dependencies
pip install -r requirements.txt

# 3. Initialize local vector database index
python scripts/ingest_docs.py --source ./internal_docs
Important Security Notice: Never paste customer PII or keys into any local prompt window unless explicitly approved by the InfoSec compliance board.

4. Frequently Asked Questions

Why did we choose Gemma 4 12B over larger 30B+ models?

The 12B configuration hits the sweet spot for consumer/workstation hardware footprints while offering native reasoning, fast inference token-speeds, and local multimodal integration without separate auxiliary vision encoders.
